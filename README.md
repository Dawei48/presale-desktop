# 放心预 - AI 预售管理系统

面向陶瓷电商的 AI 预售管理工具，一人开发，从接单到发货全链路管理。

## 功能

- **三级管理**：品牌 → 产品 → 订单
- **AI 智能导入**：支持淘宝/拼多多/抖音等平台 CSV 订单；规则匹配认不出的冷门列名，AI 语义自动识别
- **智能查重**：按订单号去重，重复导入自动跳过，不影响已手动更新的发货状态
- **订单级发货期限**：每个订单独立设期限；导入时按平台自动设（抖音 48h / 淘宝 72h / 预售 30 天），可手动改
- **发货倒计时提醒**：订单列表显示剩余天数，超时标红、临期标黄
- **云端同步**：基于 Supabase，多台电脑数据实时同步
- **团队协作**：管理员创建账号，成员登录即可查看和操作
- **产品图片**：上传产品图，自动压缩，云端存储
- **订单管理**：新增/编辑/删除订单，快捷切换状态（未发货/已发货/已完成/已取消）
- **全局搜索**：按产品名、客户名、订单号搜索
- **Word 导出**：按品牌导出未发货订单，自动合并同一产品、压缩图片，直接对接工厂
- **操作日志**：记录所有关键操作

## 下载

前往 [Releases](https://github.com/Dawei48/presale-desktop/releases) 下载最新版 `presale-desktop.exe`。

双击运行，无需安装 Python 环境。

## 使用流程

1. 首次打开 → 创建管理员账号
2. 登录 → 创建品牌 → 添加产品
3. 导入订单：各平台导出 CSV → 订单管理 → 导入 CSV → AI 自动识别列名 → 一键导入
4. 按订单的发货期限跟踪发货，超时自动标红提醒
5. 导出 Word 文档用于跟供应商/工厂对接

## 技术栈

- Python 3.11+
- CustomTkinter（UI 框架）
- Supabase（云端数据库 + 文件存储）
- DeepSeek（AI 列名识别）
- python-docx（Word 导出）
- PyInstaller（打包 .exe）
