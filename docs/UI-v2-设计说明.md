# 放心预 UI v2 — 设计说明

> 记录"为什么这么做"，避免下次重做时又回到 AI 默认审美。

## 一、技术栈变更（从根本上解决卡顿）

| | v1（旧） | v2（现在） |
|---|---|---|
| 渲染 | CustomTkinter（Tk Canvas） | pywebview + Edge WebView2 |
| 加速 | 无 GPU 加速，每个圆角卡片都是一次 Canvas 重绘 | GPU 合成 |
| 毛玻璃 | Tk 没有 alpha 合成，只能拿半透明色伪装 | CSS 真材质 |
| CSS 组件库 | galaxy/uiverse 一个都用不了 | 全部可用 |

**卡顿的真正原因不是代码写得差**，是 Tk 在 Windows 上的架构限制：滚动/切页时全部 widget 重绘。
上一版"透明卡片一改就卡"是因为用 Canvas 叠了阴影和半透明，等于每张卡都多几层重绘。

## 二、配色：三色公式

来源：抖音 @宋夏天Dazzle 的 UI 配色方法论（底色 + 主体 + 点睛）。

**两个中性色吃掉 90% 画面，一个高饱和色只占 10%，且只用在"该你动手"的地方。**

深色（默认）：
- ground `#0F0F0F` / ground-2 `#141414`（侧栏）—— 明度差 5，刚好分出层次又不脏
- ink `#F5F4F1` → `#B5B1AA` → `#8E8981` → `#6B6660` 四级
- signal `#F2743A`（窑火橙，不是灰蓝，也不是 AI 默认的靛紫）

浅色：
- ground `#F7F7F6`（中性灰白，**刻意不用暖米色**）
- signal `#C2410C`（浅底压深到砖橙，对比度才够）

> 早期版本用过 `#FAF9F7` + `#D95E1E`，正好落进 avoid-ai-design 扫描器的 **SD1「奶油底 + 陶土色」** 判定——
> 那是 Claude 自身的界面配色，AI 写"高级感"时最容易收敛到这里。已避开。

## 三、构图：去卡片化

- 整屏是一块连续面，只用 hairline（1px / 7% 白）分隔，**不套圆角卡片**。
  卡片 + 统一圆角 + 统一阴影是后台模板最重的特征。
- 页面标题 26px，分组标题 15px，行主信息 14.5px，辅助 11.5px —— 按 1.15 比例拉开。
  旧版标题 14.5px 和正文 13.5px 几乎没差，整屏"平"就是从这里来的。
- 严格列网格：客户 / 商品 / 数量 / 状态 / 操作，跨分组完全对齐。
- 橙色只标三处：Logo、主按钮、待确认延发的行内动作。侧栏选中态用中性灰，
  不让橙色兼职"选中"语义。

## 四、业务逻辑

- 首页 = 待办队列，不是仪表盘。按状态分组（待确认延发 / 待生产 / 待发货 / 预存挂账），
  每组行内直接给下一步动作。**删掉了四宫格统计**——它和分组标题是同一份信息说两遍。
- 状态机：`confirm → producing → ready → shipped → done`，加 `stored`（预存挂账，不发货不生产）。
  老数据 `pending → ready`、`completed → done` 自动映射。
- 生产单页按**窑口**聚合（窑口名从商品名第一段取），一个窑口一张单，可直接导出。
  只有 `producing`（客户已同意延发）的单才进生产单——还没同意的不能报给窑口。

## 五、导出：商务单据（不是排版作品）

`utils/docx_export_slip.py`

**走过一次弯路**：先做的是出版级三线表（booktabs，无竖线、粗顶线细中线），
自认为"专业"，但对窑口师傅来说格子不清楚，而且把 logo 弄丢了。
现在回到老版本的单据骨架，只修老版本粗糙的地方：

- 顶部居中朱砂印章 logo（2.2cm）—— 品牌感，必须有
- 标题「XX 生产单」17pt
- 五列带框表格：产品图片 / 产品名称 / 规格 / 数量 / 备注
- 表头暖墨底（#2B2724）白字 —— 老版本是深蓝 #0F172A，和红印章打架
- 斑马纹 #F0EBE4（暖砂，打印看得见；太浅等于没有）
- 边框 0.5pt #D6D1CA（不用 Word 默认黑框）
- 行高 2.3cm，图 1.9cm
- 合计行右对齐 + 「— 放心预 —」落款

一句话：**给干活的人看的单子，不是给评委看的排版。**

## 六、自审机制

- `selfcheck.py`：空库 / 计数一致性 / 状态机非法值 / 类型切换 / CSV（GBK、重复、脏行）/ docx 结构断言
- 代码层扫描：`avoid-ai-design/scripts/detect.mjs`（当前 stack 1，阈值 6 判为模板）
- 渲染层：真实 pywebview + 截图 + 视觉评审
